## Current availability

The `minuteswise` executable includes both the CLI and the local MCP server.

<Warning>
  Homebrew, standalone release binaries, and Windows package-manager distribution are forthcoming. Do not rely on those channels yet.
</Warning>

## Install from the desktop app

Open **Settings → Developers** and select **Install** (or **Reinstall**). Direct-download desktop builds copy the bundled CLI onto your PATH.

| Platform | Installed command | Path |
| --- | --- | --- |
| macOS | `minuteswise` | `~/.local/bin/minuteswise` |
| Linux (DEB / AppImage) | `minuteswise` | `~/.local/bin/minuteswise` |
| Linux (Flatpak) | `minuteswise-cli` | Preinstalled host wrapper; Settings install is optional |
| Windows | `minuteswise` | `%LOCALAPPDATA%\MinutesWise\bin\minuteswise.exe` (added to your user PATH) |

On macOS and Linux, add `~/.local/bin` to `PATH` if your shell cannot find `minuteswise`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

On Windows, open a new terminal after installing so the PATH update applies.

<Note>
  The Mac App Store build does not include bundled CLI installation. Use [build from source](#build-from-source) instead.
</Note>

## Build from source

To build the CLI yourself instead:

```bash
# Run from the MinutesWise repository root.
cargo install --locked --path apps/cli
minuteswise --version
```

`cargo` installs the executable into its configured binary directory, normally `~/.cargo/bin`. Add that directory to `PATH` if your shell cannot find `minuteswise`.

## Connect to local data

By default, the CLI looks for `minuteswise/app.db` in your operating system's application-data directory. It also recognizes legacy app locations.

Open the desktop app once so it can create the database. After that, the CLI and local MCP server work while the app is closed.

For a custom database location, pass a global option or environment variable:

```bash
minuteswise --db-path /path/to/app.db --json meetings list
MINUTESWISE_DB_PATH=/path/to/app.db minuteswise --json meetings list
```

If you have a MinutesWise data directory containing `app.db`, use:

```bash
minuteswise --base /path/to/minuteswise-data --json meetings list
```

The CLI opens the database in read-only query mode for meeting reads. Proposal create and decline commands, and `minuteswise mcp`, open the same file for writes so they can stage or discard pending edits. They do not create a database or run migrations.
